# Symbols for the user guide

The icons the frontend shows (Flutter's Material Icons), as small SVGs for the
tables of the user guide, so that they look the same on GitHub and in the PDF
(the PDF's font has no glyph for ⏮, ⏭, 🔁 and similar).

Source: [Material Design Icons](https://github.com/google/material-design-icons)
by Google, via the npm package `@material-design-icons/svg` 0.14.13, style
`filled`, file name = name of the Flutter icon (`Icons.skip_previous` →
`skip_previous.svg`). License: Apache License 2.0. Changed: a grey fill
(`#5f6b7a`) that reads on light and dark backgrounds.
